# 🧮 Python Loop Calculator

A simple command-line calculator built with Python using a `while` loop.

This project allows the user to perform basic arithmetic operations repeatedly without restarting the program.

## ✨ Features

* Addition `+`
* Subtraction `-`
* Multiplication `*`
* Division `/`
* Floor Division `//`
* Modulus `%`
* Prevents division by zero
* Handles invalid operators
* Allows repeated calculations using a loop
* Simple command-line interface

## 🛠️ Technologies Used

* Python 3
* `while` loop
* `if-elif-else`
* User input
* Basic arithmetic operators

## 🚀 How to Run

1. Make sure Python is installed on your computer.

2. Clone this repository:

```bash
git clone https://github.com/your-username/python-loop-calculator.git
```

3. Open the project folder:

```bash
cd python-loop-calculator
```

4. Run the program:

```bash
python calculator.py
```

## 💻 Example

```text
Enter the first value: 25
Enter the second value: 5
Enter any one of the operators (+, -, *, /, //, %): /

The result is: 5.0

Do you want to calculate again? (y/n): y

Enter the first value: 10
Enter the second value: 3
Enter any one of the operators (+, -, *, /, //, %): %

The result is: 1.0

Do you want to calculate again? (y/n): n
Calculator closed.
```
